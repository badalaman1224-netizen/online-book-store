# Online Book Store

An online book store website developed as a mini project to provide users with a simple interface for browsing and exploring books.

## Features
- Home page
- Book catalogue
- Login and registration pages
- Contact page
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Java (Backend)

## Project Status
A mini project developed for learning and practice.

## Future Improvements
- Online book purchasing
- Database integration
- User authentication
